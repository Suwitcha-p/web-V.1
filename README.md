# web-V.1
User 
การแจ้งปัญหาของผู้ใช้งานไม่สามารถเลือกระดับของหลุมได้ว่าอยู่ระดับไหน ทำเป็นระดับ 1-5 ระดับหลุม 
ผู้ใช้สามารถดูสถานะที่ร้องเรีนไปได้ โดยประกอบด้วย ส่งเรื่องแล้ว Received by Government Agency 
ผู้ใช้งานที่แจ้งปัญหาสามารถค้นหาพื้นที่จะแจ้งปัญหาได้

เจ้าหน้าที่ 
เจ้าหน้าที่สามารถกดรับเรื่องได้พอกดแล้วจะให้เจ้าหน้าที่อัพเดทสถานะ ประกอบด้วย

ผู้ลงพื้นที่สามารถบันทึกการลงพื้นที่ได้โดยโดยประกอบด้วย วันที่ลง( ข้อมูลเป็นวันที้ต้องใส่ ) เวลาที่ลงพื้นที่( ข้อมูลเป็นเวลาต้องใส่ ) เจ้าหน้าที่ผู้รับผิดชอบ( ตัวอักษรต้องใส่ ) สถานะภาพถนนที่ตรวจพบ( ตัวอักษรจะใส่ไม่ใส่ก็ได้ ) วิธีแก้ไข( ตัวอักษรใส่ไม่ใส่ก็ได้ ) ภาพก่อนซ่อม( เก็บเป็นข้อมูลรูปภาพต้องใส่ )
